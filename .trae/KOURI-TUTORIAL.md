\# Kouri Ai OpenAI 兼容接口 Node.js 使用教程 本教程仅介绍\*\*Node.js\*\*环境下调用Kouri Ai OpenAI兼容接口的核心操作，包含API Key配置、模型选择、接口调用（普通/流式）等核心内容，适配OpenAI官方Node.js SDK。  ## 一、前置准备 ### 1. 安装OpenAI官方Node.js SDK 确保项目中已安装OpenAI SDK，执行以下命令安装： \`\`\`bash npm install openai # 或 yarn add openai \`\`\` ### 2. 获取Kouri Ai的API Key 从Kouri Ai平台获取专属\`api\_key\`（格式为\`sk-xxxxxxxx\`），该密钥为接口调用的身份凭证，需妥善保管。  ## 二、核心配置：BaseURL与API Key Kouri Ai完全兼容OpenAI API格式，仅需修改\`baseURL\`和\`apiKey\`两个核心参数，\*\*\`baseURL\`必须添加\`/v1\`后缀\*\*，否则会报404错误。 核心配置代码： \`\`\`javascript import OpenAI from 'openai';  // 初始化OpenAI客户端，配置Kouri Ai的地址和API Key const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1', // 固定配置，不可省略/v1     apiKey: 'sk-xxxxxxxx', // 替换为你的Kouri Ai API Key }); \`\`\`  ## 三、模型选择与对应接口 Kouri Ai分两类接口适配不同模型，需根据选择的模型匹配对应接口，\*\*不可混用\*\*，核心模型-接口对应关系如下表：  | 接口类型       | 接口路径          | 适用核心模型       | 最大超时  | 核心特点                     | |----------------|-------------------|--------------------|-----------|------------------------------| | Chat Completions | /v1/chat/completions | GPT-4o、GPT-4等常规模型 | \~5分钟    | 适配大多数聊天场景，使用简单 | | Responses      | /v1/responses     | gpt-5.2-pro、o3-pro等高级推理模型 | \~20分钟 | 专为复杂推理设计，支持更高推理深度 |  \*\*注意\*\*：o1、o3等模型同时支持两个接口，平台会自动做兼容转换；但gpt-5.2-pro、o3-pro\*\*仅支持Responses接口\*\*，必须使用该接口调用。  ## 四、Chat Completions接口调用（适配GPT-4o/GPT-4等） 适用于常规聊天模型，是最常用的调用方式，支持\*\*普通同步调用\*\*和\*\*流式输出调用\*\*两种形式。  ### 4.1 普通同步调用 一次性获取模型的完整回复，适用于短文本问答、聊天等场景： \`\`\`javascript import OpenAI from 'openai';  // 初始化客户端 const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1',     apiKey: 'sk-xxxxxxxx', // 替换为你的API Key });  // 核心调用函数 async function chatCompletionsCall() {     try {         // 调用Chat Completions接口         const response = await client.chat.completions.create({             model: 'gpt-4o', // 替换为你要使用的模型（如GPT-4）             messages: \[ // 对话消息体，格式与OpenAI一致                 { role: 'user', content: '你好！介绍一下Kouri Ai' }             ]         });         // 打印模型回复内容         console.log(response.choices\[0].message.content);     } catch (error) {         console.error('调用失败：', error);     } }  // 执行调用 chatCompletionsCall(); \`\`\`  ### 4.2 流式输出调用 逐段获取模型的回复内容，适用于长文本生成、实时对话展示等场景，体验更流畅： \`\`\`javascript import OpenAI from 'openai';  // 初始化客户端 const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1',     apiKey: 'sk-xxxxxxxx', // 替换为你的API Key });  // 流式调用函数 async function chatCompletionsStream() {     try {         // 开启流式调用，添加stream: true         const stream = await client.chat.completions.create({             model: 'gpt-4o', // 适配的模型             messages: \[                 { role: 'user', content: '讲一个关于人工智能的小故事' }             ],             stream: true // 开启流式输出         });          // 逐段接收并打印内容         for await (const chunk of stream) {             const content = chunk.choices\[0]?.delta?.content || '';             process.stdout.write(content); // 不换行逐段输出         }     } catch (error) {         console.error('流式调用失败：', error);     } }  // 执行流式调用 chatCompletionsStream(); \`\`\`  ## 五、Responses接口调用（适配gpt-5.2-pro/o3-pro等） 专为高级推理模型设计，调用参数与Chat Completions不同，\*\*使用\`input\`传参\*\*，而非\`messages\`，同样支持普通调用和流式调用。  ### 5.1 普通同步调用 适用于复杂推理场景（如数学解题、代码编写、深度分析）： \`\`\`javascript import OpenAI from 'openai';  // 初始化客户端 const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1',     apiKey: 'sk-xxxxxxxx', // 替换为你的API Key });  // 核心调用函数 async function responsesCall() {     try {         // 调用Responses接口         const response = await client.responses.create({             model: 'gpt-5.2-pro', // 仅支持该类专属模型             input: '解释一下量子计算的基本原理，要求详细且易懂' // 输入提问内容         });         // 打印模型回复内容         console.log(response.output\_text);     } catch (error) {         console.error('推理接口调用失败：', error);     } }  // 执行调用 responsesCall(); \`\`\`  ### 5.2 带推理参数的调用 可配置\`reasoning\`参数指定推理深度，支持\`low\`/\`medium\`/\`high\`，满足不同复杂度的推理需求： \`\`\`javascript import OpenAI from 'openai';  const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1',     apiKey: 'sk-xxxxxxxx', });  async function responsesWithReasoning() {     try {         const response = await client.responses.create({             model: 'gpt-5.2-pro',             input: '解这道数学题：已知x²+2x-3=0，求x的所有解，并写出详细步骤',             reasoning: {                 effort: 'high' // 高推理深度，可选low/medium/high             }         });         console.log(response.output\_text);     } catch (error) {         console.error('带推理参数调用失败：', error);     } }  responsesWithReasoning(); \`\`\`  ### 5.3 流式输出调用 逐段获取推理模型的回复，适用于长文本推理生成场景： \`\`\`javascript import OpenAI from 'openai';  const client = new OpenAI({     baseURL: 'https\://api.kourichat.com/v1',     apiKey: 'sk-xxxxxxxx', });  async function responsesStream() {     try {         const stream = await client.responses.create({             model: 'gpt-5.2-pro',             input: '写一篇关于大模型发展趋势的短文，500字左右',             stream: true // 开启流式输出         });          // 逐段接收内容         for await (const event of stream) {             if (hasattr(event, 'type') && event.type === 'response.output\_text.delta') {                 process.stdout.write(event.delta);             }         }     } catch (error) {         console.error('推理接口流式调用失败：', error);     } }  responsesStream(); \`\`\`  ## 六、常见错误排查 ### 404错误 \*\*最常见原因\*\*：\`baseURL\`未添加\`/v1\`后缀，需确保配置为\`https\://api.kourichat.com/v1\`，而非\`https\://api.kourichat.com\`。 ### 模型调用错误 使用gpt-5.2-pro/o3-pro时，若调用Chat Completions接口会报错，\*\*必须切换为Responses接口\*\*。 ### 权限错误 检查\`apiKey\`是否正确，是否存在过期、权限不足等问题，替换为有效API Key即可。  ## 七、核心注意事项 1. 所有配置中，\`baseURL\`\*\*必须包含\`/v1\`\*\*，这是Kouri Ai接口的强制要求； 2. 模型与接口必须严格匹配，高级推理模型不可使用Chat Completions接口； 3. API Key为敏感信息，不可硬编码到前端代码，仅可在服务端使用； 4. 流式调用需使用\`for await...of\`语法遍历流数据，适配Node.js的异步迭代器。
