# 权限系统错误修复规范（第二轮）

## 问题描述

针对错误日志中错误 #9-14 进行全面修复。

---

### 错误 #9：LV4资源发布过程问题

**问题 1**：LV4资源发布页面描述错误
- 当前显示"普通用户上传后状态为 pending，管理员上传会直接发布"
- 应修改为"发布后会经过人工审核"

**问题 2**：学科选择框显示所有学科
- 当前显示所有学科
- 应只显示发布者所在年级的可发布学科

**问题 3**：点赞功能可以无限点赞
- 当前任何用户可以对资源无限点赞
- 应限制每个用户只能点赞一次，第二次点击为取消点赞

---

### 错误 #10：LV4发布资源后审核者找不到

**问题**：LV4发布资源后，审核面板中找不到该资源

**根本原因分析**：
- LV4资源发布后可能没有正确创建 `review_item`
- 审核队列 API 可能没有正确查询资源类型

---

### 错误 #11：LV4-LV6用户发布资源后没有删除按钮

**问题**：资源发布后，发布者无法删除自己的资源

**需求**：LV4-LV6用户发布资源后，应显示删除按钮

---

### 错误 #12：资源下载功能异常

**问题**：PDF、Word等文件类型未触发下载，直接在浏览器预览

**根本原因分析**：
- 缺少 `Content-Disposition: attachment` 响应头
- 服务器没有正确处理文件下载请求

---

### 错误 #13：任何用户可以删除/编辑其他用户的文章

**问题**：所有用户在文章页面都可以看到编辑和删除按钮，可以操作他人的文章

**根本原因分析**：
- `canManagePost` 函数权限检查不正确
- 前端模板没有正确检查文章所有者

---

### 错误 #14：无法举报文章

**问题**：举报时数据库错误 `table reports has no column named min_reviewer_level`

**根本原因分析**：
- `reports` 表缺少 `min_reviewer_level` 列
- 需要添加该列

---

## 修改内容

### 1. 修复错误 #9：资源页面描述和点赞功能

#### 1.1 修改资源发布页面描述
- 修改 `views/resources-form.ejs` 中的描述文字

#### 1.2 修改学科选择逻辑
- 在资源发布路由中根据用户年级过滤学科
- 或在前端模板中根据用户年级过滤

#### 1.3 实现点赞/取消点赞功能
- 创建 `resource_likes` 表跟踪用户点赞
- 修改点赞 API 支持取消点赞
- 前端根据点赞状态显示不同按钮

---

### 2. 修复错误 #10：资源审核队列

#### 2.1 确保资源发布时创建 review_item
- 检查 `POST /api/resources` 路由中是否调用 `createReviewItem`
- 对于 LV4 用户，资源发布后应进入人工审核队列

#### 2.2 检查审核队列 API
- 确认 `GET /api/review/items` 支持资源类型查询
- 确认 `GET /api/review/ai-reviewing` 支持资源类型查询

---

### 3. 修复错误 #11：资源删除按钮

#### 3.1 前端添加删除按钮
- 在 `views/resources.ejs` 中根据权限显示删除按钮
- LV4-LV6 用户可以看到自己资源的删除按钮

---

### 4. 修复错误 #12：资源下载功能

#### 4.1 修改下载响应头
- 在文件下载路由添加 `Content-Disposition: attachment`
- 确保 PDF、Word 等文件触发下载而非预览

---

### 5. 修复错误 #13：文章编辑/删除权限

#### 5.1 检查 canManagePost 函数
- 确认只有文章作者或 LV3+ 用户可以编辑/删除

#### 5.2 检查前端权限显示
- 在 `views/forum-detail.ejs` 中正确显示编辑/删除按钮

---

### 6. 修复错误 #14：举报功能

#### 6.1 添加数据库列
- 在 `reports` 表添加 `min_reviewer_level` 列

---

## 影响范围

### 受影响的文件
- `views/resources-form.ejs` - 资源发布表单
- `views/resources.ejs` - 资源列表
- `server/routes/resources.js` - 资源路由
- `server/routes/forum.js` - 论坛路由
- `app.js` - 主应用（canManagePost）
- `server/database/index.js` - 数据库初始化
- `views/forum-detail.ejs` - 文章详情页

### 数据库变更
- `reports` 表添加 `min_reviewer_level` 列
- 可能需要创建 `resource_likes` 表

---

## 权限矩阵（根据文档）

### 资源发布
| 等级 | 发布权限 | 审核流程 |
|-----|---------|---------|
| LV0-LV3 | 不可 | - |
| LV4 | 可发布 | 人工审核 |
| LV5+ | 可发布 | 直接发布 |

### 文章管理
| 等级 | 编辑自己文章 | 删除自己文章 | 编辑他人文章 | 删除他人文章 |
|-----|------------|------------|------------|------------|
| LV0-LV2 | 是 | 是 | 否 | 否 |
| LV3+ | 是 | 是 | 是 | 是 |
