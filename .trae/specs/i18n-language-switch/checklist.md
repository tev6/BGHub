# Checklist - 中英文切换功能验证

## 基础设施检查

- [ ] server/locales/zh.json 翻译文件存在且格式正确
- [ ] server/locales/en.json 翻译文件存在且格式正确
- [ ] public/js/i18n.js 脚本文件存在且逻辑正确
- [ ] style.css 中包含语言切换按钮样式

## 功能验证检查

- [ ] 页面右上角显示语言切换按钮组（中文/English）
- [ ] 切换按钮有明显的视觉样式区分当前选中语言
- [ ] 点击"English"后，页面文本立即变为英文
- [ ] 点击"中文"后，页面文本立即变为中文
- [ ] 切换过程无页面刷新，平滑过渡
- [ ] 刷新页面后语言偏好保持
- [ ] 关闭浏览器重新打开，自动应用上次选择的语言
