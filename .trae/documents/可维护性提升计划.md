# 项目可维护性提升计划

## Why

随着项目代码量增长，需要系统性提升代码质量、可读性和可维护性，降低后续开发与维护成本。

## What Changes

### 1. 建立代码规范与风格指南

**文件位置**：`CODE_STYLE.md`

**内容**：
- 命名约定（变量、函数、文件、数据库）
- 缩进与格式标准（2空格、120字符限制）
- 异步处理规范（async/await 优先）
- 错误处理模式
- SQL 编写规范（参数化查询防注入）

### 2. 重构现有复杂模块

**优先级一：路由模块拆分**
- 将 `app.js` 中过于集中的路由逻辑拆分
- 按功能域（auth、forum、boards、cj、homeworks、resources、chat）组织路由
- 提取公共中间件和服务

**优先级二：服务层提取**
- 提取 `auditContent`、`needsAIAudit` 等业务逻辑到独立服务
- 提取数据库查询辅助函数
- 提取权限检查逻辑

### 3. 引入自动化测试框架

**方案**：使用 Node.js 内置 `node:test` 模块

**测试覆盖目标**：
- 认证模块（注册、登录、权限）
- 论坛模块（发帖、评论、搜索）
- CJ 模块（内容编辑、日期导航）
- 资源模块（上传、下载）
- 关键业务逻辑（积分系统、审核流程）

**测试运行**：`npm test`

### 4. 建立文档体系

**需要建立的文档**：
- `API.md` - API 接口文档（使用 OpenAPI/Swagger 格式）
- `ARCHITECTURE.md` - 系统架构设计文档
- `DEVELOPER_GUIDE.md` - 开发指南（新成员入门）
- `CHANGELOG.md` - 版本变更日志

### 5. 优化项目目录结构

**现状问题**：
- `server/routes/` 和 `app.js` 边界模糊
- 服务层代码分散
- 辅助函数组织不清晰

**优化方案**：
```
BGHub/
├── server/
│   ├── routes/          # 路由处理
│   ├── services/        # 业务逻辑服务
│   ├── middleware/      # Express 中间件
│   ├── models/          # 数据模型（未来扩展）
│   ├── utils/           # 工具函数
│   └── locales/          # 国际化文件
├── tests/               # 测试文件
├── docs/                # 文档
├── public/              # 静态资源
└── views/               # 模板文件
```

### 6. 引入静态代码分析

**工具**：`ESLint` + `Prettier`

**配置**：
- 2 空格缩进
- 单引号字符串
- 无分号
- 变量声明规范（const > let > var）

### 7. 实施版本控制策略

**分支策略**：
- `main` - 生产就绪代码
- `develop` - 开发分支
- `feature/*` - 功能分支
- `hotfix/*` - 紧急修复分支

**提交规范**：
- `feat:` 新功能
- `fix:` 错误修复
- `docs:` 文档更新
- `refactor:` 重构
- `test:` 测试

## Impact

- **代码质量**：统一的代码风格提升可读性
- **开发效率**：模块化减少代码重复
- **稳定性**：自动化测试减少回归问题
- **协作**：文档和规范便于团队协作

## ADDED Requirements

### Requirement: 代码风格检查

系统必须提供代码风格检查命令。

#### Scenario: 开发者提交代码前
- **WHEN** 运行 `npm run lint`
- **THEN** 检查代码风格并报告问题

### Requirement: 自动化测试

系统必须提供测试运行命令。

#### Scenario: 验证功能正确性
- **WHEN** 运行 `npm test`
- **THEN** 执行所有测试用例并报告结果

## MODIFIED Requirements

### Requirement: package.json scripts

**现状**：
```json
{
  "scripts": {
    "start": "node app.js",
    "dev": "node app.js"
  }
}
```

**改进**：
```json
{
  "scripts": {
    "start": "node app.js",
    "dev": "node --watch app.js",
    "lint": "eslint .",
    "test": "node --test",
    "format": "prettier --write ."
  }
}
```
