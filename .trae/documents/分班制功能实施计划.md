# 分班制功能实施计划

## 需求概述

1. **年级分班制度 (G6-G8)**：
   - G6-G8 年级需要分班（3-4个班/年级）
   - 班级名称可自定义、经常变化
   - LV6 管理员面板管理班级配置
   - 不同班级的 CJ 数据隔离（例外：可配置某些 CJ 跨班共享）

2. **学科权限管理**：
   - 每个年级可设置可访问的学科 CJ（G6-G12）
   - 可设置哪些学科 CJ 在班级间共享数据
   - 不同年级可设置不同学科（可重复）

3. **用户系统改造**：
   - 注册时：G6-G8 需额外选择班级
   - 设置页面：可修改年级/班级
   - 登录用户使用账户中的年级/班级信息

4. **访客年级选择**：
   - 访客（未登录）在主页 CJ 区和 CJ 页面需选择年级
   - G6-G8 需额外选择班级
   - 选择可随时修改
   - 选择结果存储在 cookie/session 中

## 阶段一：数据库（已完成 ✓）

### 已实现的表结构

```sql
-- 班级定义表
CREATE TABLE grade_classes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  grade TEXT NOT NULL,           -- G6, G7, G8
  class_name TEXT NOT NULL,      -- A, B, C, D...
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(grade, class_name)
);

-- 学科年级权限表
CREATE TABLE subject_grade_permissions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  board_id INTEGER NOT NULL,
  grade TEXT NOT NULL,           -- G6-G12
  is_shared INTEGER NOT NULL DEFAULT 0,  -- 1=跨班共享, 0=按班隔离
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(board_id, grade),
  FOREIGN KEY(board_id) REFERENCES boards(id) ON DELETE CASCADE
);

-- 用户表新增字段
ALTER TABLE users ADD COLUMN class_name TEXT;  -- G6-G8 用户的班级

-- CJ内容表新增字段
ALTER TABLE board_sections ADD COLUMN class_name TEXT;  -- 内容所属班级
```

## 阶段四：CJ 模块改造

### 4.1 CJ 内容查询逻辑修改

**当前逻辑**：
```javascript
// 查询 CJ 内容（无视班级）
SELECT * FROM board_sections
WHERE board_id = ? AND section_date = ?
```

**新逻辑**：
```javascript
// 查询 CJ 内容（考虑班级）
const userGrade = req.user ? req.user.grade : sessionGrade;
const userClass = req.user ? req.user.class_name : sessionClass;
const isG6G8 = ['G6', 'G7', 'G8'].includes(userGrade);

// 获取学科权限
const perm = await query.get(`
  SELECT * FROM subject_grade_permissions
  WHERE board_id = ? AND grade = ?
`, [boardId, userGrade]);

// 如果该年级无权限访问此学科，返回空
if (!perm) return [];

// 构建查询条件
let classCondition = 'class_name IS NULL';  // 默认只查通用内容
if (isG6G8 && !perm.is_shared) {
  // 按班隔离的内容：class_name = 用户班级 或 class_name IS NULL(通用)
  classCondition = `(class_name = ? OR class_name IS NULL)`;
  params.push(userClass);
}
```

### 5.2 Cookie/Session 处理

**Cookie 名称**：`grade_context`

**API 端点**：
- `GET /api/grade-context` - 获取当前年级上下文
- `POST /api/grade-context` - 设置年级上下文

```javascript
// API 实现
router.post('/api/grade-context', (req, res) => {
  const { grade, class_name } = req.body;

  // 验证
  if (!['G6','G7','G8','G9','G10','G11','G12'].includes(grade)) {
    return res.status(400).json({ error: '无效的年级' });
  }

  if (['G6','G7','G8'].includes(grade) && !class_name) {
    return res.status(400).json({ error: 'G6-G8 必须选择班级' });
  }

  // 写入 cookie（7天有效期）
  res.cookie('grade_context', JSON.stringify({ grade, class_name }), {
    maxAge: 7 * 24 * 60 * 60 * 1000,
    httpOnly: false  // 前端可读
  });

  res.json({ ok: true });
});
```

## 阶段六：其他相关修改

### 6.1 路由处理 `app.js`

**需要添加的中间件**：
```javascript
// 从 cookie 读取年级上下文，存入 req.gradeContext
app.use((req, res, next) => {
  let gradeContext = null;

  if (req.user) {
    // 登录用户使用数据库中的年级/班级
    gradeContext = {
      grade: req.user.grade,
      class_name: req.user.class_name
    };
  } else {
    // 访客使用 cookie 中的年级/班级
    const cookie = req.cookies.grade_context;
    if (cookie) {
      try {
        gradeContext = JSON.parse(cookie);
      } catch (e) {}
    }
  }

  req.gradeContext = gradeContext;
  res.locals.gradeContext = gradeContext;
  next();
});
```

## 风险和注意事项

1. **向后兼容性**：已有用户的 class_name 为 NULL，需处理
2. **数据迁移**：已有 CJ 内容需要设置 class_name = NULL（表示通用）
3. **is_shared 语义**：is_shared=1 表示跨班共享，内容 class_name 存 NULL
4. **性能考虑**：每次 CJ 查询需要 JOIN permissions 表
5. **Cookie 大小**：JSON.stringify grade_context 很小，不是问题
