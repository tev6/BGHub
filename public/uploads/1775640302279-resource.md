# BG Hub社区信用等级与用户权限说明

## 核心设计理念

本社区所有功能模块（聊天、文章、资源、作业）遵循**统一的规则模型**。用户的**信用等级**决定了其在该模型下的**权限参数**。等级越高，限制越少，责任越大。

---

## 通用规则说明

### 发布机制类型

- **先审后发**：内容需经审核通过后方可公开展示

- **先发后审**：内容发布后立即可见，系统后台异步审核，违规内容将被撤回

- **免审**：内容直接发布，仅在被举报后触发审核

### 违规处罚

- **内容处置**：违规内容将被撤回或不予显示

- **功能限制**：违规行为触发临时封禁（禁止互动），时长随违规次数递增

- **信用分扣除**：根据违规内容类型扣除相应信用分

---

## 举报机制详解

### 举报适用场景

当用户发现社区内存在**违规内容**时，可对该内容发起举报，由系统或人工进行复核处理。

### 举报入口

- 每条聊天消息旁有「举报」按钮

- 每篇文章/笔记页面有「举报」按钮

- 每个资源下载页面有「举报」按钮

- 每条作业事项旁有「举报」按钮

### 举报条件

- **LV1 及以上**用户可使用举报功能

- 同一用户对同一内容**只能举报一次**

- 举报时**必须选择违规类型**（如：人身攻击、垃圾广告、色情低俗、违法违规、侵权内容、其他）

### 每日举报上限

| 等级        | 每日举报次数上限            |
| --------- | ------------------- |
| LV1–LV2   | 5 次                 |
| LV3–LV4   | 10 次                |
| LV5–LV5.5 | 20 次                |
| LV6       | 无限制（无需举报，可直接删除任何内容） |

每日额度在凌晨 0 点重置，未使用完毕不累计至次日。

### 举报处理流程

1. 用户提交举报后，被举报内容进入**审核队列**

2. 根据被举报者的等级决定审核方式（举报审核方式与内容原本的发布机制脱钩，按以下规则统一处理）：
   
   - 被举报者为 **LV0–LV2**：进入 **AI 审核**
   
   - 被举报者为 **LV3–LV4**：进入 **人工审核**
   
   - 被举报者为 **LV5**：需 **≥2 人举报**后进入人工审核
   
   - 被举报者为 **LV5.5**：进入 **人工审核**（由 LV6 审核）

3. 审核者根据社区规范作出判定

4. 系统将处理结果以通知形式反馈给举报者

### 举报结果处理

**举报成立（内容确认为违规）**

- 违规内容被撤回或隐藏

- 被举报者按违规类型扣除相应信用分

- 被举报者触发对应的临时封禁

- **举报者获得信用分奖励**：

| 举报内容类型 | 奖励信用分 |
| ------ | ----- |
| 聊天消息   | +1    |
| 作业事项   | +3    |
| 文章/笔记  | +5    |
| 资源文件   | +5    |

- **不消耗**当日举报额度（视为有效举报）

**举报不成立（内容无违规）**

- 被举报内容保持正常显示

- 被举报者不受任何影响

- 举报者不获得信用分奖励

- **消耗**当日举报额度 1 次

**恶意举报判定与惩罚**

恶意举报是指用户**故意对明显无违规的内容发起举报**的行为。

判定标准（满足任一即为恶意举报）：

- **连续 3 次**举报均不成立

- 举报理由明显与内容无关（如乱填「其他」且无说明）

惩罚措施：

| 恶意举报次数 | 惩罚                   |
| ------ | -------------------- |
| 首次判定   | 扣除 5 信用分，并警告         |
| 累计 3 次 | 扣除 15 信用分，临时封禁 1 小时  |
| 累计 5 次 | 扣除 30 信用分，临时封禁 24 小时 |

### 举报审核权限

| 被举报者等级  | 审核方式                     |
| ------- | ------------------------ |
| LV0–LV2 | AI 系统自动处理                |
| LV3–LV4 | LV4 及以上用户审核              |
| LV5     | LV5.5 或 LV6 审核（需 ≥2 人举报） |
| LV5.5   | LV6 审核                   |

### 举报通知

- 举报提交后，系统实时通知「举报已提交，请等待审核」

- 举报处理完成后，系统以站内通知形式告知举报者处理结果

- 被举报者不会被告知举报者身份（匿名保护）

## 申诉机制详解

### 申诉适用场景

当用户认为自己的内容被 AI 审核系统**误判为违规**时，可提交人工复审申诉。

### 申诉入口与条件

- 被撤回或驳回的内容旁会出现「申诉」按钮

- LV1 及以上用户可使用申诉功能

- 每条被判定违规的内容有**一次**申诉机会

### 每日申诉额度

| 等级      | 每日申诉次数上限 |
| ------- | -------- |
| LV1     | 2 次      |
| LV2     | 2 次      |
| LV3     | 3 次      |
| LV4     | 5 次      |
| LV5 及以上 | 无限制      |

每日额度在凌晨 0 点重置，未使用完毕不累计至次日。

### 申诉处理流程

1. 用户点击「申诉」后，内容进入**人工复审队列**

2. 由具有审核权限的更高等级用户进行人工复核

3. 审核者根据社区规范作出最终判定

### 申诉结果处理

**申诉成功（确认为误判）**

- 撤销原违规判定

- 内容恢复正常显示（或重新发布）

- 全额补回被扣除的信用分

- 额外补偿 3 信用分作为误判补偿

- 解除因此产生的临时封禁

- **不消耗**当日申诉额度

**申诉失败（确认为违规）**

- 维持原违规判定

- 原扣除信用分不退还

- 额外扣除 3 信用分（恶意申诉惩罚）

- **消耗**当日申诉额度 1 次

**申诉无法判定（内容处于模糊地带）**

- 按「疑罪从无」原则处理，视为申诉成功

- 但仅撤销处罚，不给予额外补偿信用分

### 申诉审核权限

| 申诉者等级   | 审核者等级       |
| ------- | ----------- |
| LV1–LV2 | LV3 及以上     |
| LV3     | LV4 及以上     |
| LV4     | LV5 及以上     |
| LV5     | LV5.5 或 LV6 |

## 补充：IP 封禁机制（仅 LV0）

- 游客在 24 小时内违规累计达 30 次，触发 IP 封禁 6 小时

- 封禁期间打开网站无法浏览任何内容

- 提供登录与注册通道，登录成功后自动解除封禁

- 管理员可手动解禁被封禁的 IP
