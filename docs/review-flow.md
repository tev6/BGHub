# BIGZ Hub 审核流程时序图

## 1. 内容提交审核流程

```
┌─────────┐          ┌─────────────┐         ┌──────────┐         ┌────────────┐
│  用户   │          │   服务端    │         │  数据库  │         │  审核员   │
└────┬────┘          └──────┬──────┘         └────┬─────┘         └─────┬──────┘
     │                      │                      │                      │
     │  1.提交内容(LV0-2)   │                      │                      │
     │─────────────────────>│                      │                      │
     │                      │  2.创建review_item   │                      │
     │                      │────────────────────>│                      │
     │                      │  3.状态=pending     │                      │
     │                      │<────────────────────│                      │
     │  4.返回"待审核"      │                      │                      │
     │<─────────────────────│                      │                      │
     │                      │                      │                      │
```

## 3. 信用值变化流程

```
┌─────────┐          ┌─────────────┐         ┌──────────┐
│  用户   │          │   服务端    │         │  数据库  │
└────┬────┘          └──────┬──────┘         └────┬─────┘
     │                      │                      │
     │  每日首次登录        │                      │
     │─────────────────────>│                      │
     │                      │  查询last_login_date│
     │                      │────────────────────>│
     │                      │  比较日期           │
     │                      │<────────────────────│
     │                      │                      │
     │  (日期不同)          │                      │
     │                      │  credit + 10        │
     │                      │  更新last_login_date │
     │                      │  写入credit_log     │
     │                      │  检查等级晋升       │
     │                      │────────────────────>│
     │                      │                      │
```

## 4. 权限等级速查表

| 等级 | 最小信用 | 可读 | 可发布 | 可审核 | 特殊权限 |
|------|---------|------|--------|--------|----------|
| LV0 | 0 | public内容 | 聊天(审核) | - | 每日5次 |
| LV1 | 50 | public内容 | 聊天(先发后审) | - | 每日10次 |
| LV2 | 150 | public内容 | article/CJ | - | 每日5篇 |
| LV3 | 300 | public内容 | resource | LV0聊天 | +5/-5, 每日20次 |
| LV4 | 500 | public内容 | article/CJ | LV0-LV2 | +3/-3, 每日50次 |
| LV5 | 800 | 全内容 | 全类型 | 全内容+日志 | 禁言7天, 每日100次 |
| LV6 | 1000 | 全内容 | 全类型 | 全内容 | 全站管理, 需密码 |

## 5. 审核状态流转

```
                    ┌──────────────┐
                    │   pending    │
                    └──────┬───────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
           ▼               │               ▼
    ┌──────────────┐       │        ┌──────────────┐
    │  approved    │       │        │  rejected    │
    └──────────────┘       │        └──────────────┘
           │               │               │
           ▼               │               ▼
    content.visible        │        credit -= 5/3
    credit += 5/3         │        notification
    notification          │               │
           │               │               │
           ▼               ▼               ▼
    ┌──────────────────────────────────────────┐
    │              review_actions               │
    │  (reviewer_id, action, reason, created) │
    └──────────────────────────────────────────┘
```
