# BGHub 使用说明

## 欢迎使用 BGHub

BGHub 是一个面向贝赛思学生的综合性学习社区平台，整合了考试日历、作业管理、资源共享和互助论坛等功能。

---

## 主要功能模块

### 1. 首页仪表盘
- 展示当天的 CJ（课件、作业、公告）内容
- 按年级和班级筛选对应的学科内容
- 日期导航可查看近7天的内容

### 2. 互助论坛
- 发布和浏览学习相关的讨论帖子
- 支持 Markdown 格式编写内容
- 点赞、评论和回复功能
- LV2+ 用户可发布文章

### 3. 资源库
- 上传和下载学习资料
- 按学科分类浏览
- LV4+ 用户可上传资源

### 4. CJ 模块
- 每日课件（IC）、作业（HW）、公告（A）
- 按年级和班级自动筛选
- LV1+ 用户可发布内容

### 5. 聊天区
- 年级群实时聊天
- LV2+ 用户发言免审核
- LV0-LV1 用户发言需 AI 审核

---

## 信用等级系统

| 等级 | 信用分 | 主要权限 |
|------|--------|----------|
| LV0 | 0+ | 浏览、聊天（审核） |
| LV1 | 50+ | 快速聊天、举报5次/日 |
| LV2 | 150+ | 免审核聊天、发布文章 |
| LV3 | 300+ | 参与审核、下载资源 |
| LV4 | 500+ | 上传资源、维护CJ |
| LV5 | 750+ | 高级权限管理 |
| LV6 | 1000+ | 管理员权限 |
