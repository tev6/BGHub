# BGHub Usage Guide

## Welcome to BGHub

BGHub is a comprehensive learning community platform for BASIS students, integrating exam calendars, homework management, resource sharing, and discussion forums.

---

## Main Features

### 1. Home Dashboard
- View daily CJ (Coursework, Homework, Announcements) content
- Filter by grade and class
- Navigate dates to view content from the past 7 days

### 2. Forum
- Post and browse learning-related discussions
- Write content in Markdown format
- Like, comment, and reply features
- LV2+ users can create posts

### 3. Resource Library
- Upload and download learning materials
- Browse by subject
- LV4+ users can upload resources

### 4. CJ Module
- Daily Coursework (IC), Homework (HW), Announcements (A)
- Auto-filtered by grade and class
- LV1+ users can post content

### 5. Chat Area
- Real-time grade group chat
- LV2+ users can chat without review
- LV0-LV1 users' messages require AI review

---

## Credit Level System

| Level | Credits | Main Permissions |
|-------|---------|------------------|
| LV0 | 0+ | Browse, Chat (reviewed) |
| LV1 | 50+ | Fast chat, Report 5x/day |
| LV2 | 150+ | Chat without review, Create posts |
| LV3 | 300+ | Participate in review, Download resources |
| LV4 | 500+ | Upload resources, Maintain CJ |
| LV5 | 750+ | Advanced admin privileges |
| LV6 | 1000+ | Full admin privileges |

---

## Usage Tips

1. **Daily login** earns credit rewards
2. **Active participation** helps level up faster
3. **Report violations** to earn credit rewards
4. **Follow community rules** to avoid penalties
